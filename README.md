# Homebrew tap for Pip

```sh
brew install --cask intelligentrascal/tap/pip-house-elf
```

Pip is a local-first desktop companion for the Mac: <https://github.com/intelligentrascal/pip>.
Apple-silicon Macs only. Upgrade with `brew upgrade --cask pip-house-elf`; remove with
`brew uninstall --cask pip-house-elf`, which leaves your saved work in `~/Library/Application Support/Pip`.
